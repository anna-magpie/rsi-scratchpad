# About

The RSI Scratchpad is a place for quick, vibecoded attempts to understand **recursive self-improvement** and the risk argument built on it. Entries are deliberately rough: toy models, back-of-envelope calculations, and short posts.

## The argument as a chain

The case for catastrophic risk from RSI is treated as seven links. The conclusion needs every link to hold, so it helps to ask, link by link, what the evidence says and what an experiment could add:

1. AI can substantially automate AI R&D
2. The loop compounds rather than plateauing
3. The result is capable enough to disempower humanity
4. Such systems are misaligned by default
5. Misalignment takes a power-seeking form
6. Oversight fails to catch it in time
7. No adequate response by default, and disempowerment means extinction

## Two kinds of entry

- **Experiments**: interactive pages (sliders, simulations, charts) that run in the browser.
- **Posts**: writing that summarises evidence, sketches a model or argues a point.

Each entry is tagged with the links it bears on, so every question page collects its own evidence trail.

## Adding an entry

See the [README on GitHub](https://github.com/anna-magpie/rsi-scratchpad#readme) for the exact recipe. In short: drop a file in `_posts/` named `YYYY-MM-DD-slug.md` (or `.html` for an interactive experiment), set `kind` and `questions` in the front matter, and push.

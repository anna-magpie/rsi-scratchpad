The argument that recursive self-improvement leads to catastrophe has several links, and **every one of them has to hold**. That makes it a good fit for piecemeal work. Each experiment or post here takes one link and tries to sharpen it a little: a toy model, a re-plot of someone's numbers, a list of observations that would change our minds.

## The links

The [home page]({{ '/#chain' | relative_url }}) lists all seven, each with a one-line verdict on the current evidence. The verdicts range from *best-supported* (automating AI R&D) through *open* (whether the loop compounds) to *mostly argument* (whether the result is decisively capable). Each link's page holds the evidence summary plus every entry tagged with it.

## Adding an entry

Create a file in `_posts/` named `YYYY-MM-DD-some-slug.md`:

```yaml
---
title: Does r look different for inference compute?
kind: post            # or: experiment
questions: [2]        # which links this bears on
summary: One sentence for the listings.
---
Write in Markdown here.
```

For an **experiment**, use `.html` instead of `.md` and put the widget straight into the file. `assets/js/viz.js` provides `Viz.line()` and `Viz.bars()` for theme-aware charts with hover tooltips. The two starter experiments show the pattern:

- [Returns to software R&D: when does the loop explode?]({% post_url 2026-11-12-returns-to-rd-toy-model %})
- [The conjunctive chain calculator]({% post_url 2026-11-12-conjunctive-chain %})

Push to `main` and GitHub Pages rebuilds the site in about a minute.
